# Minecraft Web Client

一个在浏览器中运行的 Minecraft 克隆客户端。

## 参考来源

本项目基于 [zardoy/minecraft-web-client](https://github.com/zardoy/minecraft-web-client) 构建。

## 功能特性

- 支持连接到 Java 版 Minecraft 服务器（1.8 - 1.21.5）
- 单文件构建，无需安装任何依赖
- 支持单人模式和多人模式
- 完整的资源包支持
- 支持触屏和控制器操作

## 技术栈

- TypeScript
- React
- Three.js
- Mineflayer
